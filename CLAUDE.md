# venikoff.net — сайт цветочного магазина

**Общение с владельцем — только по-русски, он не читает по-английски.** Английские кнопки интерфейсов (GitHub, Timeweb) называть с переводом и объяснять, где они.

## Бизнес
- Бренд **venikoff.net**, доставка цветов **только по Москве**.
- Основной цвет — фуксия `#E0178A` (не синий). Шрифты: Unbounded (заголовки), Manrope (текст).
- Структура каталога, карточек и порядок блоков — по образцу zeroflowers.ru; наверху своя студия-карусель букетов.
- Ассортимент: **одноголовые розы venikoff** (сорта × длина 40/50/60 см × 25/51/101 шт, прайс в `data.js` → `ROSE_PRICES`), кенийские розы 40 см, французские розы, гортензии; открытки и игрушки — «Добавить к букету».
- Цены с пометкой `est: 1` в `data.js` — расчётные, владелец должен проверить.
- Сорт «Маритим» ждёт фото. Фото новых сортов пока вырезаны из поста t.me/venikoff_net/5052 (низкое качество) — заменить на оригиналы.

## Сайт (сейчас)
- Статичный сайт: `index.html` (вся вёрстка и логика), `data.js` (каталог), `img/p` (фото товаров), `img/v` (фото сортов), `img/cut` (букеты без фона для карусели).
- Публикуется GitHub Pages из ветки `main`: https://maxmaxmax5991-prog.github.io/getbouquetsite/
- После правок в `data.js` менять номер `data.js?v=...` в `index.html` (иначе браузеры показывают старый каталог).
- Проверять в режиме телефона (375 px) перед публикацией.
- Фон с фото удаляется локально через Apple Vision (`VNGenerateForegroundInstanceMaskRequest`, Swift-скрипт).

## Сервер и админка (в работе)
- VPS Timeweb Cloud, Москва: `root@147.45.141.23`, ключ `~/.ssh/venikoff_ed25519` (на другом компьютере — свой ключ, см. `ДОМА.md`).
- Ubuntu, Caddy (веб-сервер, HTTPS), ufw (открыты 22, 80, 443).
- **PocketBase** (база + API + файлы) в `/opt/venikoff/pb`, пользователь `venikoff`, служба systemd `venikoff-pb`, слушает `127.0.0.1:8090`.
- Код сервера в `server/`: `pb_migrations/` (схема базы), `pb_hooks/` (API магазина, заказы, Телеграм-бот). Бинарник `server/pocketbase` и `server/pb_data/` в git не хранятся.
- Персональные данные покупателей (152-ФЗ) хранятся только на сервере в России.
- Ключ Телеграм-бота владелец вводит сам в настройках админки. Не вводить чужие пароли и ключи.

## Выкладка
- Сайт: `git push` в `main` → GitHub Pages обновляется за 1–2 минуты.
- Сервер: скопировать `server/pb_hooks` и `server/pb_migrations` в `/opt/venikoff/pb/`, затем `systemctl restart venikoff-pb`.
