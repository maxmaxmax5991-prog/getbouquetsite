# venikoff.net

Сайт цветочного магазина: студия сборки букета, каталог (204 позиции), карточки товаров, корзина и форма заказа.

- `index.html` — вся вёрстка и логика
- `data.js` — каталог (цены на 22.09.2026, Белгород)
- `img/p` — фото товаров, `img/cut` — букеты без фона для студии

Публикуется через GitHub Pages из ветки `main`.
