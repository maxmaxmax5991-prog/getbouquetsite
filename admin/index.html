Зоны и стоимость доставки

«Бесплатно от» — при сумме букетов от этой суммы доставка бесплатная. 0 — всегда платно.

Интервалы доставки

Доплата — например, за ночной или ранний интервал. Сегодняшние интервалы, на которые уже не успеть, сайт скрывает сам.

Прайс — это цена за букет: длина стебля × количество цветов. Таблиц может быть несколько: например, отдельно одноголовые и кустовые розы. В карточке товара выбирается, по какому прайсу он считается.

Оплата картой (CloudPayments)

  1. Зарегистрируйтесь на cloudpayments.ru и войдите в личный кабинет.
  2. Раздел Сайты → ваш сайт → там два значения: Public ID и Пароль для API (API-секрет).
  3. Вставьте их ниже и нажмите «Сохранить», затем «Проверить оплату».
  4. Пока идёт проверка документов, CloudPayments даёт тестовые ключи — сайт с ними работает так же, деньги не списываются.

Телеграм-бот

  1. В Телеграме откройте @BotFather, отправьте /newbot, придумайте имя и адрес бота (должен заканчиваться на bot).
  2. BotFather пришлёт ключ вида 123456:ABC… — скопируйте и вставьте его ниже.
  3. Откройте своего бота, нажмите Start — бот пришлёт ваш номер. Вставьте его в поле «Кто может управлять ботом».
  4. Нажмите «Сохранить», затем «Проверить бота» — в Телеграм придёт сообщение.

Что за номер: личный номер аккаунта в Телеграме (не телефон). Узнать свой — откройте бота @userinfobot и нажмите Start, он пришлёт строку «Id: 512345678». Или после сохранения ключа напишите своему боту — он ответит вашим номером.
Этим людям приходят уведомления о заказах, и только они могут менять товары через бота.
