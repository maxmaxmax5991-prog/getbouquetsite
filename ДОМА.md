# Как продолжить работу над сайтом с другого компьютера

Весь код лежит на GitHub: https://github.com/maxmaxmax5991-prog/getbouquetsite

**Рабочий сайт — https://147-45-141-23.sslip.io**, админка — https://147-45-141-23.sslip.io/admin/
Домен venikoff.net пока **не наш**: там висит чужой старый сайт, подключим свой позже.

Магазином (товары, заказы, цены, доставка) можно управлять из админки в браузере
с любого устройства — ничего устанавливать не нужно. Инструкция ниже нужна только
для работы **над самим сайтом** вместе с Claude.

---

## Шаг 1. Установить приложение Claude

1. Откройте https://claude.ai/download, скачайте приложение (Mac или Windows), войдите
   в **тот же аккаунт**, что и на работе.
2. Вверху окна выберите вкладку **Code**.

## Шаг 2. Скачать проект

Нажмите **New session** (новый сеанс) и напишите Claude:

> Склонируй репозиторий maxmaxmax5991-prog/getbouquetsite на рабочий стол и прочитай CLAUDE.md.

На Mac может появиться окно «Установить инструменты разработчика» — нажмите **Установить**
и подождите. На Windows Claude попросит поставить **Git for Windows**.

## Шаг 3. Доступ к GitHub — чтобы сохранять изменения

Ставить GitHub CLI не нужно, достаточно ключа. Напишите Claude:

> Создай SSH-ключ для GitHub и покажи мне открытую часть.

Он покажет строку, начинающуюся с `ssh-ed25519 …`. Дальше:

1. Откройте https://github.com/settings/ssh/new (войдите — вход через Google подходит).
2. **Title** (название) — например `notebook`. **Key type** оставьте `Authentication Key`.
3. В поле **Key** вставьте строку целиком и нажмите зелёную **Add SSH key**.
4. Скажите Claude: «Ключ добавлен, переключи репозиторий на SSH и проверь».

## Шаг 4. Доступ к серверу — чтобы выкладывать сайт

Для правок текстов и вёрстки сервер не нужен, но **без него изменения не попадут
на рабочий сайт**. Нужен для админки, бота, базы и любой выкладки.

1. Напишите Claude:

   > Создай SSH-ключ ~/.ssh/venikoff_ed25519 для сервера venikoff и покажи открытую часть.

2. Зайдите в Timeweb Cloud: https://timeweb.cloud/my/servers
3. **Облачные серверы → SSH-ключи → Добавить** — вставьте строку, сохраните.
4. **Это обязательно, иначе ключ не заработает:** вернитесь в **Список серверов →
   Venikoffnet → вкладка «Доступ» → SSH-ключи → «Изменить»** и **поставьте галочку**
   у нового ключа. Без этого шага ключ лежит в аккаунте, но на сервер не попадает —
   подключение будет отвечать «Permission denied».
5. Скажите Claude: «Ключ добавлен, проверь подключение к серверу».

## Шаг 5. Работать

Пишите Claude, что поменять. Например:

> Прочитай CLAUDE.md. Поменяй текст на главной: …

Claude вносит правки, проверяет их в браузере и выкладывает командой
`sh server/deploy.sh`, а потом отправляет код на GitHub.

**Если Claude пишет, что ему запретили запуск `ssh` или выкладку** — это защита
приложения, а не ошибка. Разрешите действие в окне запроса прав или выложите сами:

```
cd путь-к-проекту && sh server/deploy.sh
```

## Что сейчас ждёт заполнения в админке

- **Доставка → «Доставка по километрам»:** два ключа Яндекса (Геокодер и Геосаджест —
  это разные сервисы с разными ключами, берутся в кабинете разработчика Яндекса),
  цена за километр и минимум. Пока не заполнено — доставка считается по старым зонам.
- **Настройки → «Мессенджер MAX»:** ключ бота. Бота в MAX можно завести только
  от верифицированного юрлица РФ.
- **Товары:** под каждым фото поле «шт» — сколько цветов на этом снимке. Пока пусто,
  подписи на фото не показываются.

## Что нельзя пересылать никому (и Claude тоже)

- Пароль от Timeweb, от GitHub и от Яндекса.
- Ключ Телеграм-бота и ключи Яндекса — вводите их сами в админке.
- Файлы ключей **без** `.pub` на конце — это закрытая часть, она остаётся на компьютере.

## Если что-то пошло не так

- «Permission denied» при подключении к серверу — не сделан шаг 4.4 (галочка у ключа
  в самом сервере).
- «could not read Username for https://github.com» — репозиторий подключён по HTTPS,
  а не по SSH. Скажите Claude: «переключи origin на SSH».
- Сайт не обновился — подождите минуту и обновите страницу с Ctrl+F5 (Cmd+Shift+R).
