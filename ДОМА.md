# Как продолжить работу над venikoff.net с другого компьютера

Весь код хранится на GitHub: https://github.com/maxmaxmax5991-prog/getbouquetsite
Магазином (товары, заказы, доставка) можно управлять из админки в браузере с любого устройства, ничего устанавливать не нужно. Инструкция ниже — для работы **над самим сайтом** вместе с Claude.

---

## Шаг 1. Установить приложение Claude

1. Откройте https://claude.ai/download и скачайте приложение для своего компьютера (Mac или Windows).
2. Установите и войдите в **тот же аккаунт**, что и на работе.
3. Вверху окна выберите вкладку **Code**.

## Шаг 2. Скачать проект

1. Нажмите **New session** (новый сеанс). Если спросит папку — выберите любую, например «Документы».
2. Напишите Claude:

   > Склонируй репозиторий maxmaxmax5991-prog/getbouquetsite в папку Projects/getbuket-site в моей домашней папке и перейди в неё. Потом прочитай CLAUDE.md.

3. Если это Mac и появится окно «Установить инструменты разработчика» — нажмите **Установить** и подождите несколько минут.
   Если это Windows — Claude попросит поставить **Git for Windows**, следуйте его подсказкам.

## Шаг 3. Войти в GitHub (чтобы сохранять изменения)

Напишите Claude:

> Установи GitHub CLI и войди в мой аккаунт maxmaxmax5991-prog через браузер.

Дальше как в первый раз:
1. В терминале появится код из 8 символов.
2. Откроется браузер → проверьте, что вы в аккаунте **maxmaxmax5991-prog** (вход через Google подходит).
3. Введите код → **Continue** → **Authorize github**.

## Шаг 4. Доступ к серверу (нужен только для правок админки и бота)

Для правок страниц сайта сервер не нужен. Для изменений админки, бота и базы — нужен.

1. Напишите Claude:

   > Создай SSH-ключ ~/.ssh/venikoff_ed25519 для сервера venikoff и покажи мне его открытую часть.

2. Он покажет строку, начинающуюся с `ssh-ed25519 …`. Скопируйте её.
3. Добавьте её на сервер **одним из способов**:
   - **Timeweb Cloud**: панель → «Облачные серверы» → ваш сервер → «Доступ» / «SSH-ключи» → «Добавить» → вставить строку.
   - Если такого пункта нет: откройте этот проект на **рабочем** компьютере и попросите Claude: «Добавь на сервер venikoff этот ключ: ssh-ed25519 …».
4. Скажите домашнему Claude: «Ключ добавлен, проверь подключение к серверу».

## Шаг 5. Работать

Пишите Claude, что поменять, так же как сейчас. Например:

> Прочитай CLAUDE.md. Хочу поменять текст на главной: …

Claude сам внесёт правки, проверит и выложит на сайт.

---

## Что нельзя пересылать никому (и Claude тоже)

- Пароль от Timeweb и от GitHub.
- Ключ Телеграм-бота (вводите его только сами в настройках админки).
- Файлы `venikoff_ed25519` **без** `.pub` на конце — это закрытая часть ключа.

## Если что-то пошло не так

- «Не могу подключиться к серверу» — вероятно, ключ не добавлен (шаг 4).
- «Не могу отправить на GitHub» — нужно войти заново (шаг 3).
- Сайт не обновился — подождите 1–2 минуты и обновите страницу.
